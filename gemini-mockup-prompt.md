# Gemini Prompt: SNES Scrabble Game Mockup

Create a high-quality visual mockup of a **Super Nintendo (SNES) Scrabble-style word game** interface. This should look like a polished, professional 16-bit era game—think the visual quality of games like **Tetris Attack**, **Super Bomberman**, or **Kirby Super Star**—clean, colorful, and inviting.

## Game Concept

This is **Magpie** - a human vs. computer word game for the SNES. The player competes against an AI opponent, placing letter tiles on a 15×15 board to form words and score points.

## Visual Requirements

### Screen Layout (256×224 pixels, NTSC resolution)

Design a single gameplay screen with these elements:

1. **Game Board (Center-Left)**
   - 15×15 grid of tile spaces
   - Each cell approximately 12×12 pixels
   - Color-coded bonus squares:
     - **Triple Word** (red/dark red squares in corners and edges)
     - **Double Word** (pink/rose squares on diagonals)
     - **Triple Letter** (blue squares scattered)
     - **Double Letter** (light blue/cyan squares)
     - **Center Star** (distinctive starting square)
   - Already-played tiles should show letters with point values in corner

2. **Player's Tile Rack (Bottom)**
   - 7 tile slots in a wooden or decorative holder
   - Tiles should look tactile—slightly 3D beveled look
   - Each tile shows: large letter + small point value
   - Currently selected tile highlighted with glow or cursor

3. **Score Panel (Right Side)**
   - Player name and score (top)
   - Computer/AI name "MAGPIE" and score (below)
   - Tiles remaining in bag indicator
   - Clean, readable 16-bit style font

4. **UI Elements**
   - Current turn indicator (whose turn it is)
   - Simple button prompts: "A: Place  B: Cancel  X: Shuffle  Y: Pass"
   - Optional: Last word played / points scored display

### SNES Technical Constraints to Honor

Keep the design feasible for actual SNES hardware:

- **Color palette**: Use a harmonious 16-bit palette (SNES can display 256 colors from 32,768). Aim for a warm, inviting look—think wood tones, cream/ivory tiles, rich accent colors for bonus squares.
- **Resolution**: 256×224 pixels. Everything should be pixel-crisp, no anti-aliasing.
- **Tile graphics**: The 15×15 board + UI elements should fit comfortably. Board tiles can be 12×12 or 14×14 pixels.
- **Sprites vs backgrounds**: The board and static UI would be background layers; the cursor, selected tiles, and animations would be sprites.
- **Font**: Use a clean pixel font, 8×8 pixels for small text, larger for scores.

### Art Style Direction

- **Clean and readable** - Players need to quickly read letters and see the board state
- **Warm and inviting** - Not sterile; use wood textures, soft shadows, pleasant colors
- **Professional polish** - This should look like a first-party Nintendo or quality third-party game
- **Period-appropriate** - Looks like it belongs on SNES, not a modern retro-style game
- **Subtle depth** - Light beveling on tiles, gentle gradients where appropriate (SNES can do this)

### Color Palette Suggestions

- **Board background**: Warm cream or light tan (like a real Scrabble board)
- **Empty squares**: Slightly darker grid lines, subtle texture
- **Tiles**: Ivory/cream with brown or black letters
- **Triple Word squares**: Deep red (#C41E3A or similar)
- **Double Word squares**: Pink/salmon (#E8A0A0)
- **Triple Letter squares**: Royal blue (#2E5090)
- **Double Letter squares**: Sky blue (#87CEEB)
- **UI panel background**: Dark wood grain or deep green felt
- **Text**: Cream/white for readability on dark backgrounds

### Game State to Show

Mock up a mid-game state:
- Several words already on the board (intersecting, Scrabble-style)
- Player has 7 tiles in their rack
- Scores showing (e.g., Player: 127, Magpie: 143)
- Show the cursor/selection on one of the player's tiles or on the board
- Display should convey "it's your turn"

### Example Words on Board

Place these example words to show intersecting play:
- QUARTZ (using a triple letter on Z)
- EXAMPLE crossing it
- PIXEL below
- A few shorter words filling in

### Deliverable

Create a **pixel-perfect mockup image** at 256×224 pixels (or scaled 2x/4x for clarity while maintaining pixel art integrity). This should look like an actual screenshot from a polished SNES game.
